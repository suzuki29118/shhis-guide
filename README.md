# SHHis Guide

偶像大师闪耀色彩 SHHis 剧情整理网页。

访问地址：

```text
https://210322.xyz/
```

编辑入口：

```text
https://210322.xyz/?edit=1
```

如果要从线上当前数据重新开始编辑：

```text
https://210322.xyz/?edit=1&reset=1
```

## 文件说明

```text
index.html          网页程序和样式
data/mode-a.json    剧情简要整理数据
data/mode-b.json    相关拓展剧情数据
维护说明.md          详细维护教程
发布到GitHub.ps1     一键发布脚本
```

## 更新内容的简短流程

1. 打开 `https://210322.xyz/?edit=1`。
2. 在网页里修改内容。
3. 点击 `📦 导出网站数据文件`。
4. 在本地仓库运行 `.\发布到GitHub.ps1`。
5. 等 GitHub Pages 自动更新。

完整步骤见 [维护说明.md](维护说明.md)。
